# Local LaTeX Editor

A lightweight, fast, and free LaTeX editor that runs entirely in your browser.
No installation, no server, no subscription.

---

## ✨ Features

* ⚡ **Instant preview** — renders as you type or paste
* 📋 **Paste-friendly** — works directly with LaTeX from Gemini / ChatGPT
* 🔧 **Auto wrapping** — automatically adds `$$...$$` if missing
* 🎨 **Clean dark UI**
* 📎 **Copy LaTeX** with one click
* 🚫 **No backend required** — runs locally as a single HTML file

---

## 🚀 Getting Started

1. Download or clone this repository

```bash
git clone https://github.com/your-username/local-latex-editor.git
```

2. Open the file:

```bash
index.html
```

That’s it. No build step, no dependencies.

---

## 🧠 Usage

* Paste LaTeX directly into the left panel
* The rendered output appears instantly on the right

Example:

```latex
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
```

You can paste with or without `$$` — it will be handled automatically.

## 📦 Why this exists

Tools like MathType are:

* Paid
* Heavy
* Slow for modern workflows

This project aims to provide a minimal, fast, and free alternative for everyday use.
